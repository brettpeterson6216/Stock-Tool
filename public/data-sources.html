Data Sources

Every number on ImpliedLens traces back to a primary source. Here's exactly where each piece of data comes from and how it's used.

📈
Yahoo Finance
finance.yahoo.com

The primary source for price history, OHLCV candles, real-time quotes, key statistics, earnings summaries, and financial statements. Used for the main stock analysis, price charts, projection models, and DCF inputs. Data is fetched live on each analysis request.

Price Charts Financials DCF Inputs Projections Real-time quotes Earnings history Key statistics
🦉
Finnhub
finnhub.io

Used for analyst price targets, earnings surprises, recommendation trends, news feeds, institutional ownership, dark pool data, insider transactions, and market-wide data (movers, sector performance, VIX). All calls are server-side — your API key is never exposed to the browser.

Analyst Targets Institutional Dark Pool News Insider transactions Recommendations Market movers VIX / macro data
🏛️
SEC EDGAR
sec.gov/cgi-bin/browse-edgar

Direct access to official SEC filing data. Used for the SEC Filings section, which links to 10-K annual reports, 10-Q quarterly filings, 8-K current reports, DEF 14A proxy statements, and Form 4 insider transactions. All links point directly to SEC.gov — we do not store or proxy filing documents.

SEC Filings 10-K / 10-Q 8-K / DEF 14A Form 4 Primary source

Data Freshness and Delays

Quote data from Yahoo Finance is typically delayed 15 minutes for most exchanges during market hours. Pre-market and after-hours data is available where provided by Yahoo Finance. Historical OHLCV data is end-of-day. Analyst consensus figures are updated periodically and may lag by 24–48 hours. Institutional ownership data from Finnhub reflects the most recent 13F filings, which are filed quarterly.

What We Do Not Fabricate

All financial figures, ratios, analyst estimates, and price data shown on ImpliedLens are pulled directly from the above sources at request time. We do not generate, estimate, or fill in missing data points. If a data field is unavailable, it is shown as "—" or omitted rather than substituted. DCF models use inputs drawn from reported financials — the model itself is a calculation, not a prediction.

Important: Data accuracy depends on the upstream providers. ImpliedLens is not responsible for errors, delays, or omissions in data supplied by Finnhub, Yahoo Finance, or SEC EDGAR. Always verify critical figures against primary sources before making investment decisions.

Screener Data

The stock screener uses Finnhub's market screener API, filtered and sorted server-side. Screener results include metrics available at the time of the API call and may not reflect intraday changes.

Market Overview and Movers

The homepage market overview (indices, movers, sector performance) pulls live data from Finnhub. VIX and macro indicators use Finnhub's symbol data for ^VIX and related tickers. This data is marked as preview and does not count toward the daily analysis limit.
